PARKING LOT MANAGER - VERSION 4 - TEST LOG
Built and run with gcc -Wall -Wextra -std=c89 -pedantic : 0 warnings.

Conventions the tests rely on
  Minute = minutes from midnight of the arrival day (1440 = midnight).
  Overnight = minute out >= 1440. Rates/hour: Car 30, Bike 15, Bicycle 5.
  Flat overnight cap: Car 200, Bike 100, Bicycle 30.
  Billed hours = (minutes + 59) / 60.
